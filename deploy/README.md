# Lab 2 Deployment Assets

This folder contains deployment assets for Lab 2.

- `docker/` for service Dockerfiles and image-related notes
- `compose/` for local multi-container orchestration
- `k8s/` for Kubernetes manifests

For Lab 2 delivery, the expected progression is:

1. `docker-compose.yml` works locally
2. `deploy/k8s/` manifests exist and are reviewable
3. AWS deployment evidence is collected from the Kubernetes stack
